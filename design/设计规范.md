# 设计规范 · 政企蓝白 Enterprise Blue（定稿）

> 本规范是「Shade 壹匣」小程序与 Web 端的唯一 UI 基准，取代原方案十二「包豪斯几何」。
> 布局基准为 `布局精修.html`，交互基准为 `体验精修.html` / `体验精修-小程序.html` / `体验精修-Web.html`，宽屏基准为 `小程序-宽屏适配.html`；原 4 份首页/出工日志稿仅作历史结构参考。
> 仅颜色与圆角锁定，布局、字阶、间距、阴影、图标、导航和动效可按任务效率与可访问性持续优化。

## 一、设计定位

专业、稳重、克制、高效的班组现场作业工具。信息优先、操作为主、装饰为辅；
避免电商感、娱乐感、重渐变、厚阴影与夸张动效。

## 二、色彩 token（全端统一语义，按端映射变量）

| 用途          | 值        | 说明                                                         |
| ------------- | --------- | ------------------------------------------------------------ |
| 品牌蓝        | `#0E3DA8` | 唯一主强调：主按钮、链接、激活态、关键数据、图标             |
| 深蓝          | `#0A3592` | 仅页首/导航色带（小程序首页顶部），不作他用                  |
| 浅蓝底        | `#E8F0FF` | 图标底、徽章底、信息条底、分段激活底                         |
| 成功绿        | `#00B42A` | 验证通过 / 已完成 / 运行中（浅底 `#E8FFEA`，文字 `#0B8A37`） |
| 警告橙        | `#FF7D00` | 待处理 / 有备注 / 缺卡（浅底 `#FFF7E8`，文字 `#D25F00`）     |
| 危险红        | `#F53F3F` | 未通过 / 删除 / 未读计数（浅底 `#FFECE8`）                   |
| 页面背景      | `#F5F7FA` | 双端页面底色                                                 |
| 卡片 / 顶栏   | `#FFFFFF` |                                                              |
| 嵌套浅灰块    | `#F7F8FA` | 打卡块、月历摘要、搜索框底                                   |
| 正文          | `#1D2129` |                                                              |
| 次要文字      | `#4E5969` |                                                              |
| 辅助文字      | `#86909C` |                                                              |
| 边框 / 分隔线 | `#E5E6EB` | 发丝线 1px                                                   |
| 弱化占位      | `#C9CDD4` | 邻月日期、已读空心点                                         |

色彩规则：

- 全套界面只有一个主强调色（品牌蓝），状态色仅用于业务语义；
- 背景大面积白 / 浅灰，禁止大面积渐变与高饱和色块；
- 同一语义双端同色：验证通过绿、未通过红、待核验/有备注橙、跨班/处理中浅蓝；
- 上表为浅色基准，值与圆角不变。系统深色不是反色：Web 统一覆盖 `assets/theme.css` 语义变量，小程序由 `app.json` 开启 `darkmode`、`theme.json` 配置原生窗口，`app.wxss` 在 `prefers-color-scheme: dark` 下覆盖 `--app-*` 与 `--td-*`；页面不得另造深色色板。
- 深色下品牌蓝使用 `#78A6FF`，浅蓝底 Web `#1B2D4D` / 小程序 `#1B2F51`；正文、卡片、三级文字与状态色完整色阶以两份实际 token 文件为准。品牌深蓝页首保持 `#0A3592`，其上白字不变；链接、徽章、实心按钮前景色须分别校验对比度，不能只替换背景。
- `t-icon` 可用 `t-class` / 父级 `color` 继承 `--app-*` 语义色；若直接传内联 `color` 则用主题计算色并监听系统主题，页面、组件卸载时解除监听，回前台同步一次。图片和水印内容不做反色处理。

## 三、字体与层级

- 字体：系统无衬线栈（`"Helvetica Neue", Helvetica, Arial, "PingFang SC", "Microsoft YaHei", sans-serif`），不引入艺术字体；
- 页面标题：Web 22px / 小程序 16–18px，字重 600–700；
- 板块标题：15–16px / 600；
- 正文：13.5–14.5px / 400–600；
- 辅助说明：11–12.5px / 400，颜色 `#86909C`；
- 数字与时刻：`font-variant-numeric: tabular-nums`，关键数据 20–24px / 700；
- 三级文字颜色（`#1D2129` / `#4E5969` / `#86909C`）必须拉开层级，禁止全页同色。

## 四、圆角、阴影与间距

| 项                       | 值                                                                     |
| ------------------------ | ---------------------------------------------------------------------- |
| 卡片圆角                 | 12px                                                                   |
| 按钮 / 输入框 / 分段控件 | 8px                                                                    |
| 标签 / 徽章              | 4px（小胶囊）                                                          |
| 警示 / 提示信息块        | **直角**（未通过原因、备注、警示条等「浅底 + 左色条」一族一律方角）    |
| 图标底块                 | 10–12px                                                                |
| FAB / 头像 / 打卡字母    | 圆形                                                                   |
| 卡片阴影                 | `0 2px 8px rgba(0,0,0,.04)`，hover 加深至 `0 8px 20px rgba(0,0,0,.08)` |
| FAB 阴影                 | `0 6px 16px rgba(14,61,168,.35)`                                       |
| 页面左右边距             | 小程序 12px / Web 版心 1180px、内边距 32px                             |
| 模块间距                 | 12–16px                                                                |
| 卡片内边距               | 小程序 14px / Web 16–20px                                              |

禁止：多重阴影、深色阴影、浮雕与无意义的装饰描边；数据条、工具卡和高密度信息卡允许使用 1px `#E5E6EB` 发丝线。

## 五、组件规范

### 1. 导航

- 小程序首页：深蓝 `#0A3592` 页首（状态栏白字）+ 轻量数据条，应用入口先于通知摘要；其余页面白底导航 + 下发丝线 + 返回按钮，返回热区 ≥ 44px；
- Web 左侧可折叠导航栏：固定左栏 200px 全高，白底 + 右侧 1px 发丝线；顶部 Logo（蓝方块「匣」+ 字标），其下应用导航项（图标 19px + 名称 13.5px、38px 行高；常规次要灰，激活 = 浅蓝底 `#E8F0FF` 胶囊 + 品牌蓝 600），栏缘圆形折叠钮一键收成 64px 图标态（折叠偏好本地记忆，图标态悬停深色气泡显名称），底部用户卡（头像 + 昵称 + 角色徽章）+「管理」（仅超管）+ 退出；窄屏改为同风格抽屉，支持遮罩、Esc 关闭与焦点归还；
- Web 出工日志：常规布局为左筛选月历 + 右内容主列；≥1600px 记录页签仍保留右侧「月历 + 汇总前核验」组合，窄屏月历先显示日期与待核实数摘要，可展开完整月历。

### 2. 卡片

- 默认白底 12px 圆角 + 轻阴影；数据条、工具卡与高密度信息卡可加 1px 发丝线，不混用多套卡片语言；
- 卡片头 = 主标题（车牌 / 名称，18–20px / 700）+ 状态标签（右侧）；
- 工作台应用卡保留图标、名称、描述、标签与「进入应用」五件套，可采用横向行卡；应用为主任务区，通知为辅助侧栏；
- 出工日志 FAB 采用分组底部面板：记录与核验 / 管理与汇总，底部固定新建日志，全部入口与权限保持原口径。

### 3. 状态标签（全端统一组件）

- 小胶囊：高 22px、圆角 4px、浅底 + 同色深字 + 5px 圆点；
- 通过 `.tag.ok`（绿）、未通过 `.tag.fail`（红）、待核验/备注 `.tag.warn`（橙）、跨班/信息 `.tag.info`（浅蓝）。

### 4. 按钮

- 主按钮：蓝底白字，每页至多一枚（新建日志 / 开始巡检类核心动作）；
- 次按钮：白底 1px 边框，hover 描边变蓝；
- 文字按钮：卡片操作行使用，同步/主操作蓝、普通灰、删除红；
- 点击热区 ≥ 44px。

### 5. 分段控件与页签

- 分段（全部/仅看我）：灰底 `#EBEDF1` 胶囊槽，激活白底蓝字带轻影；
- Web 页签：下划线式，激活蓝字 + 2px 蓝条。

### 6. 月历

- 日期数字 12.5px tabular-nums，状态点 4px 圆点置于数字下方；
- 图例固定：绿 = 已验证、橙 = 有备注、红 = 待核实；
- 今天 = 蓝底白字圆角格；邻月 `#C9CDD4`。

### 7. 照片缩略图

- 圆角 8px；状态签为左上角半透明彩色小胶囊（绿/蓝/红），
  「已同步商旅」为底部渐变条内白色小字。

### 8. 表单与反馈

- 输入框：浅灰底 `#F7F8FA` 或白底 1px 边框，圆角 8px；按钮、输入与下拉使用统一焦点环，支持键盘操作；
- 列表加载用结构骨架；首载、保留旧内容的刷新、真空、搜索无结果与失败重试分态，失败不得冒充空数据；
- 弹层使用 `role=dialog` / `aria-modal`、初始焦点、Tab 圈定、Esc 关闭与焦点归还；长页滚动锁需预留滚动条槽位，禁止页面横向抖动；
- 小程序弹层为固定头部 / 独立滚动体 / 固定操作脚三段：容器纵向 flex、整体限高、滚动体 `flex:1 1 auto; min-height:0`、操作脚不收缩并含底部安全区；头部有明确关闭入口。短内容自然增高，长内容只滚动内容区，不让头部与保存按钮出屏；展开内联下拉后仍须能滚到后续字段。汇总核验与批量下载使用相同限高与关闭位置；
- Toast 使用 `role=status/alert`，错误可重试；点击反馈以浅蓝底色或约 0.98 微缩为限，禁止夸张动效。

### 9. iPad 与横屏

- 小程序启用 `resizable:true`，不强制屏幕方向，宽屏基准为 `小程序-宽屏适配.html`；600px 起字体、图标、间距、卡片、导航与控件全部改为固定 px，不能只改字阶而放任间距和按钮继续膨胀；TDesign 字号、行高、按钮及常用容器尺寸由 `app.wxss` 统一注入，不在页面另造字号 token；
- 600–899px 为紧凑单列与限宽底部弹层，首页底部 Tab 收拢居中；900–1199px 主应用页使用图标+短名称侧栏，≥1200px 使用 200px 可折叠侧栏并增大版心与列数，不能把手机单列直接拉宽。侧栏统一由 `components/wide-shell/wide-shell` 渲染，应用权限与首页 `/app/list` 同源；主应用页用 `utils/wide-page` 管理 `isWide/isTablet`，聊天、刷题、预览等二级任务页可保留专注布局，不机械套侧栏；
- 首页 ≥900px 为应用主列 + 通知辅列，“我的”为账号摘要与功能区分栏；出工日志 ≥900px 为左常驻月历/筛选 + 右日志主列，新建与日志管理进入工具栏并隐藏 FAB，≥1400px 主列充足时巡视/打卡与照片/备注双区，不足时回退单列；
- ≥900px 弹层改为居中，普通内容 560–640px、复杂表单约 760px，容器须留窗口边距；保持固定头部、独立滚动体、固定操作脚和安全区，不缩小点击热区。表格、月历与长文本按自身容器适配，不以整页横向滚动代替局部适配；
- 横竖屏切换保留当前日期、筛选、展开状态和表单草稿，不重拉无关业务数据；水印裁剪使用当前窗口尺寸，保留原图、回调、方向与既有取景中心。横竖屏与系统深色均须在真机/开发者工具复核。

## 六、动效

- 页面入场仅一次编排式上浮（`translateY(14px)` 淡出，时延链 ≤ 0.9s），落位静止，不旋转、不回弹；
- 下拉箭头旋转、选中/禁用/焦点、展开内容与筛选切换使用 120–240ms 的透明度过渡，必要时辅以小幅 transform/color/box-shadow；不能让布局高度动画拖动整页，不为纯装饰增加持续动效；
- 加载 spinner、骨架屏是状态反馈而非氛围动画；其余不做循环动效；
- 缓动 `cubic-bezier(.22,1,.36,1)`；
- 全局 `prefers-reduced-motion: reduce` 下关闭一切动画、过渡与延迟；自建组件受样式隔离影响，必须在组件 WXSS 内同步声明，不能只依赖 `app.wxss` 的原生标签选择器。TDesign 内部过渡与 `scroll-with-animation` 属原生行为，须单独核验客户端降级能力，未经真机确认不得宣称全场景降级完成。

## 七、落地映射

- Web：token 全部注入 `server/public/assets/theme.css` CSS 变量，页面组件只引用变量；
- 小程序：`app.wxss` 定义 `--app-*` 语义变量，并覆写 tdesign `--td-*` 变量
  （`--td-brand-color: #0E3DA8`、`--td-success-color: #00B42A`、`--td-warning-color: #FF7D00`、`--td-error-color: #F53F3F`、`--td-bg-color-page: #F5F7FA`、圆角与字号变量）；
- 图标：1.7px 线性 SVG 一套，双端复用（小程序可转本地 image 或 iconfont）；
  小程序宫格图标无底块，27px 深蓝线性图标直接落于白卡；Web 应用卡保留浅蓝底图标块（44px）。

## 八、禁止项

大面积渐变背景 / 复杂插画 / 厚重阴影 / 浮雕 / 多套圆角 / 多套间距 / 多套字体 /
多套按钮 / 促销感色条 / 娱乐化图标 / 仪表盘堆叠 / 每页多个主按钮。
