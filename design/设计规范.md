# 设计规范 · 政企蓝白 Enterprise Blue（定稿候选）

> 本规范是「Shade 壹匣」小程序与 Web 端的唯一 UI 基准，取代原方案十二「包豪斯几何」。
> 基准设计稿为本目录下 4 份：`小程序-首页.html` / `小程序-出工日志.html` / `Web-首页.html` / `Web-出工日志.html`。

## 一、设计定位

专业、稳重、克制、高效的班组现场作业工具。信息优先、操作为主、装饰为辅；
避免电商感、娱乐感、重渐变、厚阴影与夸张动效。

## 二、色彩 token（全端统一，双端变量同名）

| 用途 | 值 | 说明 |
|------|----|------|
| 品牌蓝 | `#0E3DA8` | 唯一主强调：主按钮、链接、激活态、关键数据、图标 |
| 深蓝 | `#0A3592` | 仅页首/导航色带（小程序首页顶部），不作他用 |
| 浅蓝底 | `#E8F0FF` | 图标底、徽章底、信息条底、分段激活底 |
| 成功绿 | `#00B42A` | 验证通过 / 已完成 / 运行中（浅底 `#E8FFEA`，文字 `#0B8A37`） |
| 警告橙 | `#FF7D00` | 待处理 / 有备注 / 缺卡（浅底 `#FFF7E8`，文字 `#D25F00`） |
| 危险红 | `#F53F3F` | 未通过 / 删除 / 未读计数（浅底 `#FFECE8`） |
| 页面背景 | `#F5F7FA` | 双端页面底色 |
| 卡片 / 顶栏 | `#FFFFFF` | |
| 嵌套浅灰块 | `#F7F8FA` | 打卡块、月历摘要、搜索框底 |
| 正文 | `#1D2129` | |
| 次要文字 | `#4E5969` | |
| 辅助文字 | `#86909C` | |
| 边框 / 分隔线 | `#E5E6EB` | 发丝线 1px |
| 弱化占位 | `#C9CDD4` | 邻月日期、已读空心点 |

色彩规则：

- 全套界面只有一个主强调色（品牌蓝），状态色仅用于业务语义；
- 背景大面积白 / 浅灰，禁止大面积渐变与高饱和色块；
- 同一语义双端同色：验证通过绿、未通过红、待核验/有备注橙、跨班/处理中浅蓝。

## 三、字体与层级

- 字体：系统无衬线栈（`"Helvetica Neue", Helvetica, Arial, "PingFang SC", "Microsoft YaHei", sans-serif`），不引入艺术字体；
- 页面标题：Web 22px / 小程序 16–18px，字重 600–700；
- 板块标题：15–16px / 600；
- 正文：13.5–14.5px / 400–600；
- 辅助说明：11–12.5px / 400，颜色 `#86909C`；
- 数字与时刻：`font-variant-numeric: tabular-nums`，关键数据 20–24px / 700；
- 三级文字颜色（`#1D2129` / `#4E5969` / `#86909C`）必须拉开层级，禁止全页同色。

## 四、圆角、阴影与间距

| 项 | 值 |
|----|----|
| 卡片圆角 | 12px |
| 按钮 / 输入框 / 分段控件 | 8px |
| 标签 / 徽章 | 4px（小胶囊） |
| 警示 / 提示信息块 | **直角**（未通过原因、备注、警示条等「浅底 + 左色条」一族一律方角） |
| 图标底块 | 10–12px |
| FAB / 头像 / 打卡字母 | 圆形 |
| 卡片阴影 | `0 2px 8px rgba(0,0,0,.04)`，hover 加深至 `0 8px 20px rgba(0,0,0,.08)` |
| FAB 阴影 | `0 6px 16px rgba(14,61,168,.35)` |
| 页面左右边距 | 小程序 12px / Web 版心 1180px、内边距 32px |
| 模块间距 | 12–16px |
| 卡片内边距 | 小程序 14px / Web 16–20px |

禁止：多重阴影、深色阴影、浮雕、描边卡片（除输入/下拉等表单控件 1px `#E5E6EB`）。

## 五、组件规范

### 1. 导航
- 小程序首页：深蓝 `#0A3592` 页首（状态栏白字），其余页面白底导航 + 下发丝线 + 返回按钮（浅灰圆角方块）；
- Web 顶栏：白底 60px，左 Logo（蓝方块「匣」+ 字标），导航激活 = 蓝字 + 2px 蓝条，右侧铃铛（红点）+ 圆形头像。

### 2. 卡片
- 一律白底 12px 圆角 + 轻阴影，无描边；
- 卡片头 = 主标题（车牌 / 名称，18–20px / 700）+ 状态标签（右侧）；
- 同页不混用多种卡片样式。

### 3. 状态标签（全端统一组件）
- 小胶囊：高 22px、圆角 4px、浅底 + 同色深字 + 5px 圆点；
- 通过 `.tag.ok`（绿）、未通过 `.tag.fail`（红）、待核验/备注 `.tag.warn`（橙）、跨班/信息 `.tag.info`（浅蓝）。

### 4. 按钮
- 主按钮：蓝底白字，每页至多一枚（新建日志 / 开始巡检类核心动作）；
- 次按钮：白底 1px 边框，hover 描边变蓝；
- 文字按钮：卡片操作行使用，同步/主操作蓝、普通灰、删除红；
- 点击热区 ≥ 44px。

### 5. 分段控件与页签
- 分段（全部/仅看我）：灰底 `#EBEDF1` 胶囊槽，激活白底蓝字带轻影；
- Web 页签：下划线式，激活蓝字 + 2px 蓝条。

### 6. 月历
- 日期数字 12.5px tabular-nums，状态点 4px 圆点置于数字下方；
- 图例固定：绿 = 已验证、橙 = 有备注、红 = 待核实；
- 今天 = 蓝底白字圆角格；邻月 `#C9CDD4`。

### 7. 照片缩略图
- 圆角 8px；状态签为左上角半透明彩色小胶囊（绿/蓝/红），
  「已同步商旅」为底部渐变条内白色小字。

### 8. 表单与反馈
- 输入框：浅灰底 `#F7F8FA` 或白底 1px 边框，圆角 8px；
- 列表加载用骨架屏；空状态 = 简洁图标 + 说明文字 + 必要操作按钮；
- 点击反馈：缩放 / 变色轻度即可，禁止夸张动效。

## 六、动效

- 仅保留一次编排式上浮入场（`translateY(14px)` 淡出，时延链 ≤ 0.9s），落位静止；
- 不做循环氛围动效；
- 缓动 `cubic-bezier(.22,1,.36,1)`；
- 全局 `prefers-reduced-motion: reduce` 下关闭一切动画与过渡。

## 七、落地映射

- Web：token 全部注入 `server/public/assets/theme.css` CSS 变量，页面组件只引用变量；
- 小程序：`app.wxss` 定义同名变量，并覆写 tdesign `--td-*` 变量
  （`--td-brand-color: #0E3DA8`、`--td-success-color: #00B42A`、`--td-warning-color: #FF7D00`、`--td-error-color: #F53F3F`、`--td-bg-color-page: #F5F7FA`、圆角与字号变量）；
- 图标：1.7px 线性 SVG 一套，双端复用（小程序可转本地 image 或 iconfont）；
  小程序宫格图标无底块，27px 深蓝线性图标直接落于白卡；Web 应用卡保留浅蓝底图标块（44px）。

## 八、禁止项

大面积渐变背景 / 复杂插画 / 厚重阴影 / 浮雕 / 多套圆角 / 多套间距 / 多套字体 /
多套按钮 / 促销感色条 / 娱乐化图标 / 仪表盘堆叠 / 每页多个主按钮。
