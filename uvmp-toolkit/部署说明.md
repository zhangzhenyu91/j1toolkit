# 部署说明（银河麒麟 V10 SP1）

## 一、需要拷贝到麒麟机器的文件

整个 `派车单导出` 目录拷过去即可，关键内容：

```
vehicle_export.py      主脚本
config.ini             配置
templates/             打印模板（派车单模板提取自系统官方页面）
offline_packages/      离线依赖包（requests、gmssl 等，备用）
```

## 二、环境准备

```bash
python3 --version          # 麒麟 V10 一般自带 3.7+，可用
which google-chrome || which chromium   # 确认有 Chrome/Chromium（你抓包用的 Chrome 就行）
```

安装 Python 依赖：

```bash
# 有网时：
pip3 install requests gmssl

# 无网时（用本目录 offline_packages）：
pip3 install --no-index --find-links=./offline_packages requests gmssl
```

**如果系统连 pip3 都没有**（麒麟最小化安装常见），任选其一：

```bash
# 办法一：装 pip（需要 sudo 和系统源）
sudo apt update && sudo apt install -y python3-pip

# 办法二：免 pip——把 wheel 直接解压到脚本旁的 pylib 目录（脚本会自动识别加载）
mkdir -p pylib
for f in offline_packages/*.whl; do python3 -m zipfile -e "$f" pylib/; done
# 之后正常 python3 vehicle_export.py 即可，无需任何安装
# 注意：websocket-client 是地图模式必需的，更新 offline_packages 后请重跑一次上面的循环
```

> 说明：gmssl 只在"账号密码自动登录（sso）"模式需要；"手动粘贴凭证（token）"模式只需要 requests。

## 三、日常使用

### 方式 A：账号密码自动登录（sso，推荐）

```bash
python3 vehicle_export.py --auth sso --month 2026-09      # 导出 9 月整月（派车单+轨迹）
```

- 首次使用建议在命令行直接输入密码（不要在 config.ini 里留密码）；也可以在 config.ini `[auth]` 里填 username，密码留空运行时输入
- 需要 gmssl 库（见上文安装）
- **首次运行请留意输出**：如果报"preLogin/check 未返回 userTicket"并打印了一段响应原文，把那段原文发给开发者调整提取规则即可

### 方式 B：手动粘贴凭证（token，备用）

1. 在麒麟上用 Chrome 登录派车系统（登录一次，凭证约 19 小时有效）
2. 按 `F12` → 切到 **Console（控制台）**，粘贴执行：
   ```js
   copy(cube.token+'\n'+cube.refreshToken+'\n'+cube.mtk)
   ```
3. 运行脚本，把剪贴板里的三行依次粘贴进去（也可以直接填进 config.ini 的 token/refresh_token/mtk）：
   ```bash
   python3 vehicle_export.py --from 2026-09-01 --to 2026-09-30 --type pcd   # 只导派车单
   ```

### 产物

产物在 `./output/`：每单一个 PDF（文件名含单号/车牌/日期）、轨迹 PDF + 轨迹点 CSV、`manifest.json`（断点续传记录，重跑自动跳过已导出单据）

## 四、每月自动运行（可选）

```bash
crontab -e
# 每月 1 号 06:30 导出上月（需 sso 模式；密码写入 config.ini [auth] password= 并 chmod 600 config.ini）：
30 6 1 * * cd /path/to/派车单导出 && /usr/bin/python3 vehicle_export.py --auth sso --month $(date -d "last month" +\%Y-\%m) >> export.log 2>&1
```

## 五、常见问题

- **提示"凭证已过期"**：重新在浏览器登录并复制三行凭证
- **提示找不到 Chrome**：`which google-chrome` 查到路径后填入 config.ini 的 `[render] chrome=`
- **PDF 版式不对**：输出目录里保留了同名 `.html` 文件，用浏览器打开它检查渲染效果，把文件发回来排查
- **轨迹图地图空白/渲染失败**：v2.0.9 起内置模板已删除，轨迹只走官方页面直出。官方渲染器起不来时按报错指引处理：在客户端「设置」页选择公司指定浏览器（真实 UVMP 页面需要它）；确认该浏览器可访问派车系统首页。地图底图（思极地图 `https://map.sgcc.com.cn`）不可达时先 `curl -I https://map.sgcc.com.cn/maps?v=3.0.0` 确认网络
- **想改派车单查询条件**：config.ini 里 `run_state`（2=已完结）、`vehicle_state`、`keep_tag`

## 六、内网工具箱（桌面客户端，推荐日常使用）

在 `vehicle_export.py` 命令行能力之上，项目内置了 Electron + Vue 桌面客户端「内网工具箱」（原生窗口 + 左侧导航 + 系统托盘，微信/QQ 形态；业务核心为 Python sidecar，经 stdio JSON-RPC 调用），麒麟 amd64/arm64 与 Windows 10+ 通用，GitHub Actions 提供三架构安装包。架构与开发规范见《内网工具箱开发指南.md》。

包含两个应用：
- **每日派车单同步**：整合重写自 export_dispatch_orders.py（playwright 链路 → 纯接口链路），每日定时导出当日全部状态派车单为 `yyyy-mm-dd-派车单.xlsx` 写入 GLKVM U盘；产物格式与旧脚本完全一致
- **派车单·轨迹导出**：给定派车单号清单（xlsx 文件或粘贴文本），按清单顺序导出派车单 PDF、轨迹 PDF、轨迹点 CSV 到指定目录（命名规则见开发指南第十章），支持断点续传

### 安装

**方式 A：安装包（推荐）**——从 Release 下载：
- Windows：`uvmp-toolkit-Setup-x.y.z.exe`——免管理员安装，自动建桌面/开始菜单快捷方式、注册每日导出计划任务、带卸载程序（卸载自动删计划任务）
- 麒麟：`sudo apt install ./uvmp-toolkit_x.y.z_arm64.deb`（或 amd64）——装到 `/opt/uvmp-toolkit`（桌面菜单显示名「Shade 壹匣 - 内网」），afterInstall 自动建初始配置（`~/.config/uvmp-toolkit/config.json`，定时默认停用）、装 systemd timer 与桌面菜单项；卸载 `sudo apt remove uvmp-toolkit`（配置保留）

**方式 B：绿色包**——解压 zip/tar.gz 即用（config.json 在程序旁生成）；定时需手动注册：`install\windows\install.bat`（源码模式亦同）。

**方式 C：源码 CLI 兜底（无 GUI）**——整个项目目录拷到内网机，跑 `sudo bash install/linux/install.sh`（仅每日定时导出；GUI 请用安装包）。

> 客户端仍需目标机自带 Chrome/Edge（PDF 渲染用）。Electron 若在老旧麒麟上起不来（glibc/arm64 兼容），回退方式 C。

### 使用

- 启动客户端：双击桌面「内网工具箱」；已运行时再双击只会唤起窗口（单实例）
- 首次使用：导航 → 设置，确认 SSO 账号密码已配置
- 改每日导出时间：每日派车单同步 → 定时设置，即时生效，无需 sudo
- 按单号导出：派车单·轨迹导出 → 选 xlsx 或粘贴单号 → 选输出目录（原生目录对话框）→ 开始导出
- 运维命令：
  ```bash
  systemctl list-timers uvmp-toolkit.timer      # 下次触发
  systemctl start uvmp-toolkit.service          # 手动执行一次
  journalctl -u uvmp-toolkit.service            # 定时运行日志
  /opt/uvmp-toolkit/resources/core/uvmp-core selfcheck   # 核心自检
  ```
- 任务日志：客户端页内实时日志，另存 `~/.local/share/uvmp-toolkit/logs/`（root 定时器在 `/root/.local/share/uvmp-toolkit/logs/`；Windows 计划任务日志在 `resources/core/daily-export.log`）

### 卸载

```bash
sudo apt remove uvmp-toolkit                   # deb 安装（配置保留）
sudo bash install/linux/uninstall.sh           # 源码 CLI 模式
```

### 常见问题（工具箱）

- **客户端打不开**：deb 绿色包装到非系统盘试试；确认 `libatomic1` 已装（deb 已声明依赖）；麒麟个别安全策略需 `--no-sandbox`（在桌面菜单项 Exec 后追加）
- **定时没执行**：`systemctl list-timers` 看定时器；再看客户端状态页「上次成功/最近任务」与 `journalctl -u uvmp-toolkit.service`——到点前、今日已执行、配置停用都会跳过（due-check 设计如此）
- **重复导出同名文件**：新旧两套定时器并存了，`systemctl disable --now export-dispatch-orders.timer` 停用旧版
- **本机调不出数据想先看界面**：设置 → 高级 → 开发模式（dev.mock）用模拟数据演示，**正式使用务必关回**
