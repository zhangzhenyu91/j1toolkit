# 轨迹地图排查手册（给 AI 助手）

> 背景：轨迹 PDF 的地图区域空白。原因是无头 Chrome 没有思极地图平台的登录态。
> 本手册通过 3 个实验确定解决方案。请严格逐条执行。
> 规则：
> 1. 每条命令单独执行，看完输出再执行下一条，不要跳步
> 2. 不要修改任何 .py 文件；除明确指示外不要编辑文件
> 3. 报告中**原样粘贴**命令输出，不要总结省略；**不要粘贴 config.ini 内容**（含密码）
> 4. 命令超时设 300 秒；不需要 sudo

---

## 第 0 步：进入目录

```bash
cd "/data/usershare/浏览器自动化/派车单导出"
ls vehicle_export.py probe_map_auth.py config.ini
```

预期：三个文件都在。缺 `probe_map_auth.py` → 停止，报告缺文件。

## 实验 A：带浏览器 profile 的无头渲染（验证"cookie 就是全部障碍"）

### A1. 关闭统一浏览器并找到 profile 目录

```bash
pkill -f browser360ent; sleep 2
ls ~/.config/ | grep -i 360
```

把输出原样记录（可能形如 `browser360ent-cn-stable` 或 `browser360ent`）。以下命令中如出现 `<PROFILE>`，替换为这里看到的实际名字。

### A2. 复制 profile

```bash
rm -rf "/data/usershare/浏览器自动化/派车单导出/.prof"
cp -r ~/.config/<PROFILE> "/data/usershare/浏览器自动化/派车单导出/.prof"
du -sh "/data/usershare/浏览器自动化/派车单导出/.prof"
```

### A3. 找一个已有的轨迹 html 文件

```bash
ls output_test2/轨迹_*.html 2>/dev/null | head -1
```

- 有结果 → 记下完整路径，后续用 `<HTML>` 代替
- 没有 → 执行 `ls output_test/轨迹_*.html 2>/dev/null | head -1`，仍没有就报告"没有 html 文件"，跳到实验 B

### A4. 用该 profile 无头渲染

```bash
/usr/bin/browser360ent-cn-stable --headless=new --no-sandbox --ignore-certificate-errors \
  --user-data-dir="/data/usershare/浏览器自动化/派车单导出/.prof" \
  --virtual-time-budget=20000 \
  --print-to-pdf=/tmp/maptest.pdf "<HTML>"
ls -la /tmp/maptest.pdf
```

### A5. 记录结果

- `/tmp/maptest.pdf` 生成了 → 报告"实验A产物已生成，请人工打开确认地图是否显示"，并注明文件大小
- 没生成 → 把终端输出原样报告

> 视觉确认由人工完成：地图显示 = profile/cookie 方案可行；地图仍空白 = 进入实验 C。

## 实验 B：SSO 会话能否自动获取地图资源（验证"全自动登录"可行性）

```bash
cd "/data/usershare/浏览器自动化/派车单导出"
python3 probe_map_auth.py 2>&1 | tee probe.log
```

- 如果提示输入密码，输入 config.ini 里那个 SSO 密码
- 完成后把 `probe.log` 全文原样写入报告

**判读（照做即可）**：
- 若 `styles/aegis/Streets` 或 `tiles` 相关 URL 返回 `HTTP 200` 且"响应前200字符"含 `{` 或 `PNG` → 报告"地图资源可直接获取"
- 若重定向到 `sso.tyqx.sgcc.com.cn` 再跳回并最终 200 → 报告"CAS 自动登录成功"
- 若最终是登录页 HTML 或 401/403 → 报告"地图平台独立认证"

## 实验 C：抓取地图资源的真实请求（仅在 A 空白且 B 显示独立认证时执行）

> 需要图形界面。若无 GUI 权限，跳过并注明。

1. 用**统一浏览器**打开实验 A3 找到的那个 `轨迹_xxx.html`（在文件管理器双击，或地址栏输入完整 file:// 路径）
2. 确认地图显示后按 `F12` → **Network** → 刷新一次页面
3. 在请求列表找一条 `map.sgcc.com.cn` 域名、`api` 或 `style` 或 `tile` 字样的请求（不是 maps?v=3.0.0 那条）
4. 右键 → **Copy → Copy as cURL**，粘贴保存为：
   `/data/usershare/浏览器自动化/派车单导出/diag_map_curl.txt`
5. 同时在 **Console** 执行 `document.cookie` 把输出行也保存到该文件末尾

报告 `diag_map_curl.txt` 已生成。

## 报告格式

```
【A1 profile 目录名】：
【A4 结果】：PDF 已生成(大小) / 失败(输出)
【A 人工视觉确认】：（由人工补充：地图显示/空白）
【B probe.log 关键行】：地图资源可直接获取 / CAS自动登录成功 / 独立认证 / 其他
【C diag_map_curl.txt】：已生成 / 跳过
【原始输出】：（probe.log 全文；A4 失败时的输出）
```
