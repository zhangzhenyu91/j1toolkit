# 派车系统抓包操作步骤（内网机器上执行）

> 目的：抓取浏览器与派车系统之间的接口请求（HAR 文件），用于编写自动导出脚本。
> 预计用时：15 分钟。无需安装任何软件。
> 执行环境：内网机器 + Chrome 或 Edge 浏览器。

---

## 一、准备浏览器（2 分钟）

- [ ] 1. 打开 Chrome/Edge，先**不要**登录派车系统
- [ ] 2. 按 `F12` 打开开发者工具（如果按 F12 没反应，点浏览器右上角菜单 → 更多工具 → 开发者工具）
- [ ] 3. 点开发者工具顶部的 **Network**（网络）标签
- [ ] 4. 勾选面板上的两个选项：
  - ☑ **Preserve log**（保留日志）——防止登录跳转时清空记录
  - ☑ **Disable cache**（停用缓存）——保证所有请求都被记录
- [ ] 5. **最关键的一步**：点开发者工具右上角的 **齿轮图标（设置 ⚙）**，在设置列表里找到并勾选：
  - ☑ **"Auto-open DevTools for popups"**（为弹出窗口自动打开开发者工具）
  - 原因：派车单的"批量打印"和轨迹的"打印预览"都会弹出新窗口，不开这个选项，弹窗里最关键的打印接口就抓不到

## 二、完整操作一遍业务流程（10 分钟）

保持开发者工具打开，按顺序操作：

### 登录
- [ ] 1. 在地址栏输入派车系统地址，正常走 SSO 登录（选单位 → 输账号密码 → 登录），直到进入系统首页

### 派车单批量打印
- [ ] 2. 进入 **运行管理 → 派车单管理**
- [ ] 3. 设置查询条件：
  - 时间范围选一个**小一点的区间**（比如最近一周，减少数据量）
  - 状态勾选 **"已完结"**（去掉"未执行、执行中"）
- [ ] 4. 点 **查询**，等列表出来
- [ ] 5. 把每页条数改成 **50**
- [ ] 6. 勾选表头复选框 **全选** 本页记录
- [ ] 7. 点 **批量打印**
- [ ] 8. **等打印预览弹窗完全加载出来**（能看到单据内容即可，不用真的打印，也不要急着关）
- [ ] 9. 弹窗完全加载后，停留 3 秒，再关闭弹窗

### 行驶轨迹打印
- [ ] 10. 进入 **监控管理 → 行驶轨迹**
- [ ] 11. 设置起止时间为**同一天**（如 09:01 00:00 ~ 09:01 23:59），点 **查询**
- [ ] 12. 任选一条有数据的记录，点 **查看**（进入轨迹详情）
- [ ] 13. 点 **打印预览**，**等弹窗完全加载出来**，停留 3 秒，再关闭

### 结束
- [ ] 14. 回到系统首页即可，**先别关浏览器**

## 三、导出 HAR 文件（2 分钟）

- [ ] 1. 切回**主窗口**的开发者工具（Network 面板）
- [ ] 2. 在请求列表的**空白处点右键** → 选 **"Save all as HAR with content"**（全部保存为包含内容的 HAR）
  - 保存为：`zhu.har`
- [ ] 3. 检查：如果刚才打印弹窗弹出过自己独立的开发者工具窗口，且该窗口还开着，也在它的 Network 面板空白处右键 → 同样保存，命名为：`print.har`
  - 如果弹窗的开发者工具已经随弹窗关闭了，没关系，`zhu.har` 里通常已经包含弹窗请求
- [ ] 4. 验证文件：右键 `zhu.har` → 用记事本打开，能看到的文本里应包含 `uvmp` 等网址，文件大小一般有几 MB

## 四、手写补充记录（1 分钟）

新建一个 `说明.txt`，按下面模板填写：

```
测试日期范围（派车单）：2026-__-__ ~ 2026-__-__
派车单查询结果大约条数：____
点"批量打印"的大致时间：__点__分
轨迹测试用的车牌号：________
轨迹测试日期：2026-__-__
点"打印预览"的大致时间：__点__分
打印出来的派车单包含哪些内容（简述，如：车牌/驾驶员/用车人/起止地点/事由）：
________________________________
轨迹打印预览是表格还是带地图：________
```

- [ ] 如果方便：把打印预览界面用手机拍个照，或手动"打印成 PDF"存一份样例（脱敏后）一起拷出

## 五、脱敏（必做，1 分钟）

HAR 文件里含有登录 cookie 和可能的密码，拷出前先处理：

- [ ] 1. 用记事本（或 Notepad++）打开 `zhu.har`
- [ ] 2. `Ctrl+F` 搜索你的**登录密码**，把每一处替换为 `***`
- [ ] 3. 搜索你的**姓名/身份证号/手机号**等敏感信息（如果有），同样替换
- [ ] 4. 保存文件（保持 .har 后缀不变）

> 说明：脚本编写只需要接口的网址、参数结构，不需要有效凭证，放心替换。

## 六、拷出

把以下文件用 U 盘拷到分析机器的 `E:\派车单导出\` 目录：

- [ ] `zhu.har`（必需）
- [ ] `print.har`（如果有）
- [ ] `说明.txt`
- [ ] 打印样例 PDF / 照片（如果有）

## 常见问题

**Q1：操作完了 Network 面板里一条记录都没有？**
A：开发者工具必须是操作**之前**打开的。重新按 F12 打开后再操作一遍。

**Q2：右键没有 "Save all as HAR with content"？**
A：右键要点在**请求列表的空白区域**（不是某一条请求上）。Edge 旧版本可能只有 "Save as HAR"，选它也可以。

**Q3：点批量打印后弹窗被浏览器拦截了？**
A：地址栏右侧点"已拦截弹出式窗口"图标 → 选择"始终允许"，然后重新点一次批量打印。

**Q4：zhu.har 里搜不到打印相关的请求，怀疑弹窗请求没抓到？**
A：确认第一步第 5 条的 "Auto-open DevTools for popups" 已勾选，然后只重做"派车单批量打印"和"轨迹打印预览"两步，重新导出 HAR。

**Q5：实在抓不全怎么办？（备用方案，一般用不到）**
A：在麒麟机器上安装 Reqable（官网 reqable.com 有 Linux 版），开启系统代理抓包，重复上面操作后导出 HAR。使用前注意其代理会影响全局网络。
