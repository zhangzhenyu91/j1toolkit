# 安全日活动记录

## 主要功能

用户上传文档（pdf、doc、docx、ppt、pptx、xls、xlsx）、填写日期，然后系统自动生成文档的安全日活动记录文件。

## 技术方案

Dify 已有成熟工作流

1. Dify 工作流仅能接收单个文件，需要将用户上传的文件做处理：

    a. 如果用户仅上传了一个文件，则直接使用 Dify 工作流处理。

    b. 如果用户上传了多个文件，则需要将多个文件合并为一个文件，然后使用 Dify 工作流处理。

2. Dify 工作流调用方式：

    a. 上传文件 `base_url` 和 `api_key` 从env中读取：

    ```
    curl -X POST '{base_url}/v1/files/upload' \
    --header 'Authorization: Bearer {api_key}' \
    --form 'file=@localfile;type=image/[png|jpeg|jpg|webp|gif]' \
    --form 'user=abc-123'
    ```

    b. 生成安全日活动记录文件工作流 `base_url` 和 `api_key` 从env中读取，均与上传文件工作流相同，`response_mode` 有两种模式：`streaming` 和 `blocking`：

    ```
    curl -X POST '{base_url}/v1/workflows/run' \
    --header 'Authorization: Bearer {api_key}' \
    --header 'Content-Type: application/json' \
    --data-raw '{
    "inputs": {
        "document": {
            "transfer_method": "local_file",
            "upload_file_id": "{upload_file_id}",  //上传文件 ID，string字符串
            "type": "document"
        }
        "date": "2025.06.01",                      //日期，string字符串
        "name": "《刘总在安全例会上的讲话》"             //文件名，string字符串
    },
    "response_mode": "streaming",
    "user": "zhangzhenyu91"
    }'
    ```

## 执行逻辑

1. 用户上传文档，弹出文件名编辑框，默认填入用户上传的文件的文件名，中间以顿号隔开，首尾加上书名号，例如：《用户上传的文件1的文件名、用户上传的文件2的文件名》，由用户编辑后，点击确定，即生成文件名 `name` 。

2. 日期选择，默认填入当前日期，或由用户选择日期（展开日历选择），格式为 `YYYY.MM.DD` ，作为 `date` 。

3. 点击生成按钮，先将用户上传的文件合并为一个PDF文件，然后调用 Dify 工作流，无需等待返回，显示生成中即可，工作流完成后，会在 `/docs` 中生成一个 `{date}.docx` 的文件，即为生成的安全日活动记录文件，生成完毕的判断你可以检测这个文件或做一个接收请求端，我让dify在完成工作流后发送请求，然后我再去检测这个文件是否存在。

4. 需要一个记录模块，展示历史生成的记录，如果还未完成，就转圈显示生成中，如果完成，就展示文件（要有文件名），点击下载，可以下载到本地。

## 登录验证（已接入「检修一班工具箱」统一权限）

平台仅允许「检修一班工具箱」中拥有「安全日活动记录」（app_key `safe-day`）应用权限的用户登录使用：

1. 登录页提交账号密码 → 后端转发主平台 `POST {J1TOOLKIT_API_URL}/api/v1/auth/app-login`，一次完成账号密码 + 应用权限校验；
2. 校验通过后签发自有会话 JWT 写入 HttpOnly Cookie（`sdl_session`），后续请求自动携带；
3. 未登录访问主页重定向到登录页，其余 API 一律 401；`/api/callback`（Dify 回调）豁免；
4. 相关环境变量：`J1TOOLKIT_API_URL`（必需）、`SESSION_SECRET`、`SESSION_EXPIRES`、`PROXY_PREFIX`、`COOKIE_SECURE`，详见 `.env.example`。
