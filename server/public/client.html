取件方式（Docker 产物镜像，tag = 版本号）

  • 镜像内 /artifacts/ 含 6 个安装包：Windows 安装包（Setup exe）/ 绿色包（zip）、麒麟 amd64 / arm64 的 deb 与 tar.gz。
  • 优先腾讯云 TCR（与服务器同云）：ccr.ccs.tencentyun.com/j1net/j1toolkit:uvmp-<版本号>
docker create --name tmp ccr.ccs.tencentyun.com/j1net/j1toolkit:uvmp-<版本号> docker cp tmp:/artifacts/ ./uvmp-installers docker rm tmp
  • 备用 GitHub GHCR：ghcr.io/zhangzhenyu91/uvmp-toolkit:<版本号>（命令同上，替换镜像地址即可）
  • 镜像仓库若未设公开，需先 docker login 对应仓库。

安装说明

  • Windows 10+：下载「安装包（exe）」双击安装（免管理员）；绿色包（zip）解压即用。
  • 银河麒麟 V10 SP1：下载对应架构（amd64 / arm64）的 deb，执行 sudo apt install ./uvmp-toolkit_*.deb。
  • 安装后打开客户端，在「设置」页填写 SSO 凭据，再到「每日派车单同步」页启用定时。
  • Gitee / GitHub 均为公开仓 Release，浏览器直链下载、免登录；Gitee 侧单附件超 100MB 会分卷（cat 文件名.part-* > 文件名 合并）。
