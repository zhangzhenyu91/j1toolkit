取件方式（Docker 产物镜像）

  • 产物镜像地址：docker.cnb.cool/j1net/j1toolkit/j1toolkit-private:<版本号>（如 :2.5.9，最新版本号见 CNB 制品页）。
  • 镜像内 /artifacts/ 含 6 个安装包：Windows 安装包（Setup exe）/ 绿色包（zip）、麒麟 amd64 / arm64 的 deb 与 tar.gz。
  • 取件命令（需先 docker login docker.cnb.cool）：
docker create --name tmp docker.cnb.cool/j1net/j1toolkit/j1toolkit-private:<版本号> docker cp tmp:/artifacts/ ./uvmp-installers docker rm tmp

安装说明

  • Windows 10+：下载「安装包（exe）」双击安装（免管理员）；绿色包（zip）解压即用。
  • 银河麒麟 V10 SP1：下载对应架构（amd64 / arm64）的 deb，执行 sudo apt install ./uvmp-toolkit_*.deb。
  • 安装后打开客户端，在「设置」页填写 SSO 凭据，再到「每日派车单同步」页启用定时。
  • 访问 CNB 制品库需登录有私有仓权限的 CNB 账号；无账号时也可从 GitHub 私有仓 Release 下载（同样需要账号权限）。
